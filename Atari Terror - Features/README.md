# Atari Terror — Features

This folder contains the interactive fan-creature generator prototype and the connected Atari Terror website and shop previews.

## Open the prototype

Start at [Atari Terror Creatures](at-creatures-prototype/index.html).

The prototype includes the song selection flow, generated fan creature cards, the sample gallery, trending mockups, and previews for poster, T-shirt, and fan pass outputs. Results and likes are stored locally in the browser; this is a front-end prototype and does not send user data to a server.
